# Reference Data Import Templates

These are empty import templates only. They intentionally contain no fabricated legal or national reference records. Populate them from officially approved DLF/government/reference sources, validate them, then import through controlled seed/import tooling.

- `admin_units.csv` — hierarchical Country/Province/District/Commune/Village data.
- `organizations.csv` — ministry/department/division/subnational organization structure with effective dates.
- `countries.csv` — country codes/names.
- `species.csv`, `breeds.csv` — controlled animal/aquatic taxonomy used by the platform.
- `legal_instruments.csv` — verified law/decree/decision/notice metadata.
- `regulatory_rules.csv` — versioned rules linked to verified legal instruments.
- `service_configuration.csv` — service/version/workflow status mapping.

Do not publish imported regulatory configuration until legal/domain owners approve it.
