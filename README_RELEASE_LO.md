# LVSP — ສະບັບທົດລອງສຳລັບພະແນກສັດຕະວະແພດ

ເລີ່ມຈັດເຮັດ 4 ຕຸລາ 2026; ສົ່ງມອບ 5 ຕຸລາ 2026. ເວີຊັນ `1.12.0-release-candidate.1`.

ຊຸດນີ້ພ້ອມເປີດທົດລອງໃນເຄື່ອງ ແລະ ທົດສອບໃນ PostgreSQL ແລ້ວ. ຍັງບໍ່ໄດ້ Push ຫຼື Deploy ຂຶ້ນເວັບຈິງ. ການຢືນຢັນວ່າຄົບທຸກວຽກພະແນກຕ້ອງອາໄສລາຍຊື່ວຽກ ແລະ ແບບຟອມທາງການ.

## ເປີດລອງໃຊ້ດຽວນີ້

1. ໃນ Finder ເປີດໂຟນເດີ `LVSP_RELEASE_20261004`.
2. ດັບເບິນຄລິກ `START_REVIEW.command`.
3. ເປີດ browser ທີ່ `http://localhost:8787`.
4. ບັນຊີທົດລອງ: `admin`; ລະຫັດ: `lvsp-demo-change-me`.
5. ເລືອກ “ວຽກປະຈຳເດືອນ / ງົບປະມານ” ເພື່ອລອງໜ້າໃໝ່.

ໃຫ້ເປີດໜ້າ Terminal ໄວ້ຂະນະນຳໃຊ້; ກົດ Control+C ເພື່ອຢຸດ. ຖ້າເປີດໄຟລ໌ບໍ່ໄດ້ ໃຫ້ເປີດ Terminal ໃນໂຟນເດີນີ້ ແລະ ໃຊ້ `bash START_REVIEW.command`.

ຂໍ້ມູນທົດລອງເກັບໃນ `apps/api/runtime/review-data.json`. ບັນຊີນີ້ໃຊ້ສະເພາະທົດລອງໃນເຄື່ອງ. ໜ້າທະບຽນຢາແບບລະອຽດ, ລາຍງານແຂວງ ແລະ ບາງຟັງຊັນຕ້ອງໃຊ້ Neon/PostgreSQL ທົດລອງ. ການຢືນຢັນວຽກ/ງົບປະມານຕ້ອງໃຊ້ພະນັກງານອີກຄົນ ໃນລະບົບບັນຊີ PostgreSQL.

## ສິ່ງທີ່ເພີ່ມ ແລະ ແກ້ໄຂ

- ວຽກປະຈຳເດືອນ: ແຜນ, ຜົນປະຕິບັດ, ໝາຍເຫດ, ສົ່ງກວດ, ສົ່ງຄືນ, ຢືນຢັນ ແລະ CSV.
- ງົບປະມານພາຍໃນພະແນກ: ງົບຕາມແຜນ/ລາຍຈ່າຍຈິງເປັນເງິນກີບ; ສັງລວມສະເພາະລາຍການຢືນຢັນ. ເປັນການຕິດຕາມພາຍໃນ; ບໍ່ໄດ້ກຳນົດອຳນາດອະນຸມັດງົບທາງການ.
- ເປີດເມນູລາຍງານແຂວງ/ປະຈຳເດືອນ ແລະ ແກ້ວັນສຸດທ້າຍຂອງເດືອນຕາມເຂດເວລາລາວ.
- ກວດສິດ API ທີ່ຂຽນແຍກ, ປ້ອງກັນການແກ້ສະຖານະຜ່ານ payload ຂອງ generic command, ແລະ ແຍກໄຟລ໌ test.
- ກຽມ Vercel adapter, GitHub CI, migration ແລະ ຄຳສັ່ງອັບເດດ.

## ຂຶ້ນ GitHub / Vercel

ຕ້ອງຮູ້ລິ້ງ GitHub `laovetdb` ທີ່ຖືກຕ້ອງ, ມີສິດເຂົ້າ repository, ແລະ ຮູ້ Vercel project ປັດຈຸບັນກ່ອນ. ອ່ານ `docs/RELEASE_DEPLOYMENT.md` ສຳລັບຂັ້ນຕອນລະອຽດ.

1. ຕິດຕັ້ງ Git ຄັ້ງດຽວຜ່ານ Apple Command Line Tools (`xcode-select --install`), ແລ້ວ clone repository ທີ່ຖືກຕ້ອງ.
2. ດັບເບິນຄລິກ `UPDATE_GITHUB.command` ແລະ ປ້ອນທີ່ຢູ່ໂຟນເດີ clone. Script ຈະກວດ test, ສ້າງ branch ໃໝ່, commit ແລະ push branch ນັ້ນ.
3. ເປີດ Pull Request ໃນ GitHub ແລະ ກວດ Vercel Preview.
4. ກຽມ Neon ທົດລອງ, ສຳຮອງຖານຂໍ້ມູນ, ແລະ ກວດ migration `000920` / `000930` ກ່ອນນຳໃຊ້.
5. ຫຼັງທົດລອງຜ່ານ ແລະ ອະນຸມັດແລ້ວ ຈຶ່ງ merge ເຂົ້າ production branch. Vercel ຈະ deploy ອັດຕະໂນມັດເມື່ອ project ເຊື່ອມກັບ branch ນັ້ນແລ້ວ.

ຄຳສັ່ງນີ້ບໍ່ force-push ແລະ ບໍ່ merge ເຂົ້າ production ດ້ວຍຕົນເອງ. ໄຟລ໌ລັບ, ຂໍ້ມູນ runtime ແລະ ຂໍ້ມູນ legacy ສົ່ງອອກ ບໍ່ລວມໃນຊຸດ upload.
