# LVSP v1.6 — True Legacy Workspaces Phase 1

- Veterinary Drug Registration ປ່ຽນຈາກ generic resource list ເປັນ task-centric workspace: Registry, Dossier/Review, filters, expiry warnings, Memo Center, Central Report ແລະ detail/certificate ຂອງເດີມ.
- Import / Export / Transit ຖືກລວມເປັນ workspace ດຽວ: Annual Plans & Balance, Applications/Permits, Clearance, ANIMUSE/AMR.
- Provincial Reporting ແລະ helper resource menus ຖືກຊ່ອນຈາກ sidebar ໂດຍບໍ່ລຶບ code/data.
- Trade application form ຮອງຮັບ IMPORT / EXPORT / TRANSIT, origin/destination, entry/exit checkpoint, transport, purpose, decision/permit/clearance fields.
- Permit print ເລືອກ checkbox IMPORT/EXPORT/TRANSIT ຕາມ movement type ຈິງ.
- Annual plan overview ອີງ `analytics.v_import_plan_item_balance`, ດັ່ງນັ້ນຍອດຖືກຄິດຈາກ Actual Cleared Quantity.
- Central Reports ຍັງເປັນ report engine ກາງ; Company/Product Master ຍັງເປັນ shared master.
- No database migration in v1.6 Phase 1.
