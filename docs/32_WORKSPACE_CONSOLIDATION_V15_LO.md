# LVSP v1.5 — Workspace Consolidation Phase 1

- Registration Memo Center is inside Veterinary Drug Registration, not a duplicate sidebar module.
- Central Reports is the single report engine: Work Area → Report Type → filters → columns → preview → PDF/Word/Excel/CSV.
- Duplicate Drug/Trade detail report buttons are removed.
- Registration Memo A4 tables use fixed layout, wrapping and repeated headers.
- Certificate printing uses a direct body print host and waits for assets to prevent blank previews.
- Provincial Reporting stays disabled; its stale My Work card is hidden without deleting historical DB data.
- VM-1003 shows REVIEW rather than 0/8 in My Work.
- No database migration is added.
