# ຂອບເຂດວຽກພະແນກ ແລະ ການທົດລອງ

## ຂໍ້ມູນທີ່ຈຳເປັນຕໍ່ການປິດຂອບເຂດ

ໃຫ້ພະແນກລະບຸແຕ່ລະວຽກ: ຊື່ວຽກ, ຜູ້ຮັບຜິດຊອບ, ຂໍ້ມູນຮັບເຂົ້າ, ຂັ້ນຕອນ, ຜູ້ກວດ/ຜູ້ອະນຸມັດ, ແບບຟອມຜົນອອກ, ກົດອາຍຸ/ຄ່າທຳນຽມທີ່ຢືນຢັນ, ລາຍງານຕ້ອງການ ແລະ ຜູ້ມີສິດເບິ່ງ.

## ລາຍການທົດລອງກັບພະນັກງານ

- [ ] ບັນຊີແຕ່ລະຄົນ, ປ່ຽນລະຫັດຄັ້ງທຳອິດ ແລະ ສິດຕາມໜ້າທີ່.
- [ ] ທະບຽນຢາຕົວຢ່າງຈິງ: ສ້າງ, ກວດ, ສົ່ງຄືນ, ອະນຸມັດ, ພິມ ແລະ ຕິດຕາມອາຍຸ.
- [ ] ຄຳຮ້ອງນຳເຂົ້າ/ສົ່ງອອກ: ລາຍການ, ຫົວໜ່ວຍ, ແຜນ, ໃບອະນຸຍາດ ແລະ ຜົນຜ່ານດ່ານ.
- [ ] ລາຍງານແຂວງ: ຮັບ, ກວດຢືນຢັນ, ສັງລວມ ແລະ ປຽບທຽບຍອດກັບເອກະສານຈິງ.
- [ ] ວຽກ/ງົບປະມານ: ປ້ອນ, ສົ່ງກວດໂດຍຄົນໜຶ່ງ, ຢືນຢັນໂດຍອີກຄົນ, ກວດຍອດ ແລະ CSV.
- [ ] ກວດປະຫວັດການແກ້ໄຂ, ການສຳຮອງ/ກູ້ຄືນ ແລະ ການອັບເດດເວັບ.
- [ ] ຢືນຢັນວ່າທຸກວຽກຈຳເປັນຂອງພະແນກມີໃນຂອບເຂດທີ່ຕົກລົງ.

ການທົດສອບ automated ບໍ່ແທນການຢືນຢັນແບບຟອມ ແລະ ຂັ້ນຕອນທາງການຂອງພະແນກ.
