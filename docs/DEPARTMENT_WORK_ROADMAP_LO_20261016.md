# ແຜນເພີ່ມໜ້າວຽກພະແນກ — 16 ຕຸລາ 2026

ຜູ້ໃຊ້ລະບຸໃຫ້ເພີ່ມວຽກເຫຼົ່ານີ້ຫຼັງຈາກເຊື່ອມລະບົບປັດຈຸບັນສຳເລັດ. ເອກະສານນີ້ແມ່ນແຜນພັດທະນາ; ບໍ່ໄດ້ໝາຍຄວາມວ່າໜ້າວຽກທັງໝົດເປີດໃຊ້ຈິງແລ້ວ.

## ລຳດັບວຽກ

1. ເຮັດທະບຽນຢາ ແລະ ການຄ້າຢາ/ANIMUSE ປັດຈຸບັນໃຫ້ພ້ອມ: ທົດສອບເວັບ, ກວດຂໍ້ມູນເກົ່າ, ຍ້າຍຂໍ້ມູນແບບກວດທຽບໄດ້, ແລະ ຈຶ່ງປ່ຽນເວັບຫຼັກ.
2. ເພີ່ມວຽກນຳເຂົ້າ/ສົ່ງອອກ/ສົ່ງຜ່ານຜະລິດຕະພັນສັດ.
3. ເພີ່ມວຽກນຳເຂົ້າ/ສົ່ງອອກ/ສົ່ງຜ່ານສັດມີຊີວິດ ແລະ ເອກະສານຢັ້ງຢືນສຸຂະພາບສັດເພື່ອສົ່ງອອກ.
4. ເພີ່ມວຽກນຳເຂົ້າ/ສົ່ງອອກສັດລ້ຽງສວຍງາມ ເຊັ່ນ ໝາ, ແມວ.
5. ເພີ່ມວຽກອອກໃບອະນຸຍາດຫ້ອງຂາຍຢາສັດ.
6. ເພີ່ມວຽກອອກໃບອະນຸຍາດຄລິນິກປິ່ນປົວສັດ.
7. ວຽກອື່ນຕາມລາຍການໜ້າທີ່ຂອງພະແນກທີ່ຜູ້ໃຊ້ຈະຢືນຢັນເພີ່ມ.

## ຫຼັກການສ້າງ

ໃຊ້ LVSP ເດີມ ແລະ ຖານ Neon ຮ່ວມກັນ. ແຕ່ລະໜ້າວຽກມີແບບຟອມ, ຂັ້ນຕອນກວດ/ອະນຸມັດ, ສິດຜູ້ໃຊ້, ເລກເອກະສານ, ລາຍງານ ແລະ ປະຫວັດຂອງຕົນ. ໃຊ້ບັນຊີ, ຜູ້ປະກອບການ, ສະຖານທີ່, ດ່ານ ແລະ ບ່ອນເກັບເອກະສານຮ່ວມກັນ.

ບໍ່ຄວນເອົາແບບຟອມຢາດຽວໄປໃຊ້ກັບທຸກວຽກ. ການຄ້າສັດ/ຜະລິດຕະພັນສັດ ແລະ ໃບອະນຸຍາດຮ້ານຄ້າ ຕ້ອງມີຂໍ້ມູນສະເພາະຂອງວຽກ. ANIMUSE ນັບສານຕ້ານເຊື້ອຕາມຂອບເຂດລາຍງານ ບໍ່ເອົານ້ຳໜັກສັດ ຫຼື ຜະລິດຕະພັນສັດມານັບເປັນ kg ຢາ.

ກ່ອນສ້າງແຕ່ລະວຽກ ຕ້ອງກວດແບບຟອມ/ໃບອະນຸຍາດທີ່ພະແນກໃຊ້ຈິງ, ຜູ້ມີສິດລົງນາມ ແລະ ຂັ້ນຕອນອະນຸມັດ. ສຳລັບໃບຢັ້ງຢືນສົ່ງອອກ ຕ້ອງກວດແບບທີ່ຕົກລົງກັບປະເທດປາຍທາງ ແລະ ຂໍ້ກຳນົດທີ່ມີຜົນໃນເວລານັ້ນ. ບໍ່ຄາດເດົາເງື່ອນໄຂທາງການ ຫຼື ສ້າງລາຍເຊັນຜູ້ມີອຳນາດ.
