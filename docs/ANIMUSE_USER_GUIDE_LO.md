# LVSP — ທະບຽນ ແລະ ANIMUSE

ເປີດວຽກ ນຳເຂົ້າ–ສົ່ງອອກ → ANIMUSE. ໃຊ້ບັນຊີ LVSP ເດີມ.

## ຢາທີ່ມີທະບຽນ

ຄົ້ນຫາຊື່ຢາ ຫຼື ເລກທະບຽນ ແລ້ວເລືອກຂະໜາດບັນຈຸທີ່ກົງກັນ. ລະບົບດຶງສ່ວນປະກອບທີ່ລະບຸຊັດເຈນມາຊ່ວຍປ້ອນ. ກວດກັບສະຫຼາກ/ເອກະສານຈິງ ແລະ ລະບຸແຫຼ່ງຫຼັກຖານກ່ອນຢືນຢັນ. ລະບົບບໍ່ເລືອກຂະໜາດທຳອິດແທນໃຫ້.

## ຢາທີ່ບໍ່ມີທະບຽນ ຫຼື ຍັງເຊື່ອມບໍ່ໄດ້

ເລືອກ UNREGISTERED ຫຼື NOT_LINKED. ບັນທຶກຊື່ຢາ, ຈຳນວນຜ່ານດ່ານຈິງ, ຂະໜາດບັນຈຸ, ສານອອກລິດແຕ່ລະຕົວ, ຄວາມແຮງ, ຫົວໜ່ວຍ, ກຸ່ມ WOAH ແລະ ຫຼັກຖານ. ນັບໃນວຽກເຝົ້າລະວັງໄດ້ເມື່ອຂໍ້ມູນຄົບ ແລະ ກວດຢືນຢັນແລ້ວ. ການບັນທຶກນີ້ບໍ່ໄດ້ອອກທະບຽນ ຫຼື ອະນຸຍາດນຳເຂົ້າໃຫ້.

## ວິທີນັບ

ຕົວຢ່າງສົມມຸດ: 200 ຂວດ × 100 ml × 100 mg/ml ÷ 1,000,000 = 2 kg ຂອງສານອອກລິດ.

- ປ້ອນຈຳນວນຈິງ; ບໍ່ໃຊ້ຈຳນວນໃນແຜນ ຫຼື ທີ່ຂໍອະນຸຍາດແທນ.
- 1 L = 1000 ml; ນ້ຳໜັກຜະລິດຕະພັນ 1 kg = 1000 g. ບໍ່ປ່ຽນ ml ເປັນ g ໂດຍຄາດເດົາ.
- kg active ແມ່ນນ້ຳໜັກລວມຂອງສານນັ້ນໃນແຖວເອກະສານ, ບໍ່ແມ່ນນ້ຳໜັກລວມສິນຄ້າ/ຫີບຫໍ່.
- ຢາປະສົມແຍກນັບແຕ່ລະສານ. ບໍ່ໃສ່ສານດຽວກັນຊ້ຳສອງແຖວ.
- % ຕ້ອງລະບຸ w/v ຫຼື w/w. IU ຕ້ອງມີຄ່າແປງສະເພາະສານພ້ອມອ້າງອີງ.
- ຂາດຄວາມແຮງ/ຫຼັກຖານ/ຈຳນວນ = ລໍຖ້າກວດ; ບໍ່ແມ່ນ 0 kg.

ກົດ ກວດສູດ → ບັນທຶກລໍຖ້າກວດ → ຜູ້ມີສິດກວດຢືນຢັນ. ລາຍງານຈຶ່ງຈະນັບລາຍການນັ້ນ. ການແກ້ໄຂຈະກັບເປັນລໍຖ້າກວດ. ຍົກເລີກໃຊ້ Void ພ້ອມເຫດຜົນ; ປະຫວັດຍັງຢູ່ໃນ audit.

ປີລາຍງານອີງວັນຜ່ານດ່ານຈິງ. ນຳເຂົ້າ, ສົ່ງອອກ, ສົ່ງອອກຄືນ ແລະ ຜ່ານແດນແຍກກັນ. ນຳເຂົ້າສຸດທິ = Import − Re-export ເປັນຍອດເບື້ອງຕົ້ນ; ຕ້ອງທຽບ stock ແລະ ແຫຼ່ງຂໍ້ມູນອື່ນກ່ອນລາຍງານລະດັບຊາດ. ບໍ່ບວກຍອດຂາຍ/ໃຊ້ໃນຟາມຊ້ຳກັບຍອດນຳເຂົ້າ.

CSV ນີ້ເປັນໄຟລ໌ສຳລັບກວດທຽບ; ຍັງບໍ່ແມ່ນແມ່ແບບສົ່ງ ANIMUSE ທາງການ. ຕ້ອງກວດກັບແມ່ແບບ WOAH ຂອງຮອບລາຍງານນັ້ນ.
